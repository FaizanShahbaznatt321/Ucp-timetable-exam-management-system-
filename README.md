Implemented the UCP Timetable & Exam Management System as a C++ console-based Programming Fundamentals project.

PF concepts demonstrated:
- Functions and function prototypes
- Parameter passing and references
- Pointers and pointer arithmetic
- Dynamic memory allocation using new/delete
- Dynamic 1D and 2D-style pointer-based arrays
- C-style character arrays
- String comparison and safe copying
- Input validation
- Searching, updating, adding and deleting records
- Dynamic array auto-growth and auto-shrink
- File handling using fstream
- Saving and loading data from files
- Date and time validation
- Room and instructor clash detection
- Nested loops and conditional logic
- Menu-driven console application
- Proper memory deallocation

The project manages both timetable records and examination schedules and includes persistent data storage through text files.
